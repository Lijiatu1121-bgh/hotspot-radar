2赛道：钱和注意力在往哪走

括号内是本期该赛道的项目数，柱长是该赛道星速中位数（每天涨多少星）。用中位数而非总和，避免单个爆款拉偏整个赛道。
💡 怎么用：赛道柱长代表「同样的项目质量，放在这个赛道能多拿多少关注」。 柱长明显高于全局中位（143 星/天）的赛道，说明当下有系统性红利—— 这时候做该赛道的解读内容，天然比冷门赛道更容易被算法推。
